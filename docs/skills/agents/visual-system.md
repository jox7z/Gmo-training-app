# Sistema de agentes visuales GMO

## Routing

| Orden | Agente | Entrega |
|---|---|---|
| 1 | `codebase-explorer` | Contratos, consumidores y archivos |
| 2 | `gmo-visual-director` | Concepto, jerarquía, estados y allowlist |
| 3 | `supabase-fullstack-engineer` | Solo si existe impacto cross-layer |
| 4 | `react-native-ui-engineer` | Presentación RN/Expo |
| 5 | `motion-performance-engineer` | Motion semántico con layout estable |
| 6 | `mobile-visual-qa` | Evidencia visual read-only |
| 7 | `react-native-performance-auditor` | Evidencia FPS/render/image/bundle |
| 8 | `build-verify` | Gates automatizados |
| 9 | `code-quality-reviewer` | Bugs y arquitectura |

## Dirección

- Público: adultos jóvenes gym-first.
- Estética: gym editorial industrial.
- Negro dominante, crema GMO, rojo decisivo.
- Métricas grandes, fotografía 4:5, superficies rectas y densidad útil.
- MotionSites inspira composición/coreografía; nunca se copia como UX móvil.
- Accesibilidad sigue siendo requisito base, no una estética geriátrica.

## Boundary

Agentes visuales no editan Supabase, auth, repos, queries, stores, persistencia,
Query keys, buckets, uploads ni privacidad. Escalan:

```text
boundary:
behavior:
affected_contracts:
data_or_privacy_risk:
required_owner:
visual_work_blocked:
```

## Evidencia

- 360/390/430/768.
- Loading, contenido, vacío, error, offline, teclado y Reduce Motion.
- Screenshots y dispositivo/OS.
- Sin aprobación física basada solo en lectura de código.
