Lead with the change or finding, not with commentary. No preambles ("I'll now..."), no farewells, no summaries of what was just done.

**Why:** User explicitly set this as project communication rule.

**How to apply:** Every response — take direct action and report concrete results. Report findings first, then the evidence.
